# B2B-SaaS-MySQL-PowerBI
B2B SaaS marketing and sales analytics on a synthetic, AI-generated 11-table dataset (~255K rows). MySQL for import, cleaning (mixed date formats, JSON parsing) and transformation; 4-page Power BI report with DAX, Power Query, incremental refresh and query folding. KPIs: MRR, ARR, churn, CAC, ROAS, CPL, CTR, win rate, LTV.
